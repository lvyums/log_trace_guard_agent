## 一、项目概述

### 1.1 项目简介

**日志溯源卫士智能体（Log Trace Guard Agent）** 是一个 AI 驱动的日志分析与安全实训平台，采用模块化五层架构，集成日志解析、采集规划、脚本生成、合规审计和攻防实训五大核心功能模块。

### 1.2 技术栈

| 组件 | 技术选型 |
|------|---------|
| 后端框架 | FastAPI (Python 3.10) |
| 向量库 | ChromaDB |
| LLM 对接 | 自定义 LLMFactory (OpenAI 兼容接口) |
| 规则引擎 | 正则 + 风险基线 双引擎 |
| 前端 | 原生 HTML/CSS/JS (SPA 架构) |
| 数据存储 | 外部 JSON 配置 + 内存 Session |

### 1.3 五层分层架构

```
┌─────────────────────────────────────────────┐
│  app/   — FastAPI入口、路由挂载、全局异常    │
│  modules/  — 五大业务模块（零耦合）          │
│  core/     — AI工厂、规则引擎、上下文管理器   │
│  common/   — 日志、文件、JSON、返回封装工具   │
│  data/     — 向量库、规则库、案例库           │
└─────────────────────────────────────────────┘
```

### 1.4 核心设计规范

- **工厂注册模式**: 所有策略通过 `register()` 外部注册，禁止硬编码实例化
- **配置外置**: 所有映射表、阈值、推荐文本存放 `data/rule_data/` JSON 文件
- **Pydantic 校验**: 所有 API 入参通过 Pydantic 模型强类型校验
- **兜底设计**: 未知场景统一返回兜底方案 + 人工复核提示
- **模块零耦合**: 业务模块禁止互相 import，跨模块数据走 ContextManager
