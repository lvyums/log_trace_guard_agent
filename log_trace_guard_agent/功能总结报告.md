## 一、项目整体概览

日志溯源卫士智能体（Log Trace Guard Agent）是一个 AI 驱动的日志分析与安全实训平台，采用模块化五层架构，集成了 **5 大核心业务模块、25 个 API 端点、20 个 JSON 外部配置库**。

### 1.1 五层架构

```
┌───────────────────────────────────────────────┐
│  app/          FastAPI 入口、路由挂载、全局异常  │
│  modules/      五大业务模块（零耦合）            │
│  core/         AI 工厂、规则引擎、上下文管理器    │
│  common/       日志、文件、JSON、返回封装工具     │
│  data/         向量库、规则库、案例库             │
└───────────────────────────────────────────────┘
```

### 1.2 核心设计规范

| 规范 | 实现状态 |
|------|---------|
| 工厂注册模式 — 策略通过 `register()` 外部注册 | ✅ 全部实现 |
| 配置外置 — 映射/阈值/知识库存放 JSON 文件 | ✅ 20 个外部配置 |
| Pydantic 校验 — 所有入参强类型校验 | ✅ 全模块覆盖 |
| 兜底设计 — 未知场景返回兜底 + 人工复核 | ✅ 全部实现 |
| 模块零耦合 — 禁止互相 import | ✅ 严格约束 |

### 6.1 合规标准问答

![标准问答](screenshots/15-合规审计-标准问答.png)

**API 测试结果**:
```json

Request:  {"question": "日志留存需要多久"}
Response: 含等保2.0/网安法/数安法标准引用，10+ 条标准匹配

关键答案:
- 网络安全法：日志留存时间不少于6个月
- 等保2.0三级：日志记录保存6个月以上
- 日志字段需包含：事件时间、用户标识、源IP/目的IP、操作类型、事件结果
```

✅ 基于知识库检索，返回标准引用 + 详细说明 + 检查方法 + 违规风险
