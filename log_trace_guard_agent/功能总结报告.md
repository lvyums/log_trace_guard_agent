# 日志溯源卫士智能体 — 功能总结报告

> **生成日期**: 2026-08-05  
> **项目版本**: v3.2.0  
> **运行环境**: FastAPI + Python 3.10 + Vue 3 + Element Plus + Vite  
> **服务地址**: http://localhost:8000

---

## 一、项目整体概览

日志溯源卫士智能体（Log Trace Guard Agent）是一个 AI 驱动的日志分析与安全实训平台，采用模块化七层架构，集成了 **7 大核心业务模块、46 个 API 端点、5 个 RAG 知识库（ChromaDB）、6 大 CLI 命令行功能**。

### 1.1 七层架构

```
┌──────────────────────────────────────────────────┐
│  app/          FastAPI 入口、路由挂载、全局异常     │
│  modules/      七大业务模块（零耦合）               │
│  core/         AI 工厂、规则引擎、上下文管理器、RAG  │
│  common/       日志、文件、JSON、返回封装工具        │
│  data/         ChromaDB 向量库、规则库、案例库      │
│  frontend/     Vue 3 + Vite 前端工程               │
│  tests/        模块测试用例                        │
└──────────────────────────────────────────────────┘
```

### 1.2 核心设计规范

| 规范 | 实现状态 |
|------|---------|
| 工厂注册模式 — 策略通过 `register()` 外部注册 | ✅ 全部实现 |
| 配置外置 — 映射/阈值/知识库存放 JSON 文件或 ChromaDB | ✅ 5 个 RAG 知识库 + JSON 配置 |
| Pydantic 校验 — 所有入参强类型校验 | ✅ 全模块覆盖 |
| 兜底设计 — 未知场景返回兜底 + 人工复核 | ✅ 全部实现 |
| 模块零耦合 — 禁止互相 import | ✅ 严格约束 |

## 三、模块一：日志解析 🔍

**功能**: 日志类型识别 → 结构化解析 → 风险研判 → 批量处理

**API 路由**: `/api/v1/log-parse/`

### 3.1 日志识别

**API 端点**: `POST /api/v1/log-parse/identify`

自动识别日志类型（SSH/Web/WAF/Firewall/DB 等），返回设备类型和置信度评分。基于正则特征库 + LLM 降级双引擎确保高准确率。

### 3.2 结构化解析

**API 端点**: `POST /api/v1/log-parse/parse`

从原始日志中提取 18+ 个结构化字段（IP、端口、用户、操作、事件类型、时间戳等），支持 SSH、Web（Apache/Nginx/IIS）、WAF、防火墙、数据库等多种日志格式的专用解析器。

### 3.3 风险研判

**API 端点**: `POST /api/v1/log-parse/assess`

基于风险规则引擎 + 特征加权识别攻击行为，返回风险等级（P0-极高危/P1-高危/P2-中危/P3-低危/正常）、攻击类型和修复建议。

### 3.4 字段释义

**API 端点**: `POST /api/v1/log-parse/explain` / `explain/batch`

对日志中的字段进行自然语言释义，帮助安全运维人员理解字段含义和业务上下文。

### 3.5 批量解析

**API 端点**: 
- `POST /api/v1/log-parse/parse/batch` — 文本批量解析（含风险研判）
- `POST /api/v1/log-parse/upload` — 上传日志文件
- `POST /api/v1/log-parse/parse/batch-file` — 从上传文件批量解析
- `POST /api/v1/log-parse/cleanup` — 清理临时文件

支持一次提交多条日志或上传日志文件，批量完成识别+解析+风险研判一体化处理，单次最大处理 500 条。

## 四、模块二：日志采集 📡

**功能**: 设备匹配 → 采集方案生成 → 故障诊断

**API 路由**: `/api/v1/log-collect/`

### 4.1 设备匹配

**API 端点**: `POST /api/v1/log-collect/match`

基于设备类型/型号/规模，自动匹配合适的采集协议和方案，支持 scale 枚举（small/medium/large/enterprise）。

### 4.2 采集方案

**API 端点**: 
- `POST /api/v1/log-collect/plan` — 单设备采集方案
- `POST /api/v1/log-collect/plan/batch` — 批量采集方案

根据设备参数生成详细采集配置模板（协议、端口、传输方式、步骤说明），支持包含或排除详细配置代码。

### 4.3 故障诊断

**API 端点**: 
- `POST /api/v1/log-collect/fault/diagnose` — 多维度联合诊断（症状+协议+设备+原始日志）
- `GET /api/v1/log-collect/fault/list` — 获取所有故障类型列表

## 五、模块三：规划咨询 📊

**功能**: 架构推荐 → 平台选型 → 指导手册

**API 路由**: `/api/v1/advisory/`  
**新增于 v3.1**

### 5.1 架构推荐

**API 端点**: `POST /api/v1/advisory/architecture/recommend`

根据设备数量、日日志量、预算、团队技能水平，推荐合适的大数据采集架构（ELK / Loki + Promtail + Grafana / Splunk / ClickHouse 等），包含架构图和技术要点。

### 5.2 平台选型

**API 端点**: `POST /api/v1/advisory/platform/choose`

根据企业规模、日志量、预算、团队技能、功能需求等多维度评估，推荐最佳日志平台 + 备选方案对比分析。此功能从 v0.1.0 脚本生成模块移至规划咨询模块。

### 5.3 指导手册

**API 端点**: `POST /api/v1/advisory/guide/generate`

根据使用场景（规模、设备类型、采集方案、架构、平台等），生成定制化部署指导手册，涵盖实施步骤、注意事项、常见问题。

## 六、模块四：脚本生成 ⚙️

**功能**: 正则生成 → ES 查询 → 攻击溯源 → 脚本优化 → Splunk 集成

**API 路由**: `/api/v1/script-gen/`

### 6.1 正则生成

**API 端点**: 
- `POST /api/v1/script-gen/regex` — 单场景正则
- `POST /api/v1/script-gen/regex/batch` — 批量正则生成

根据攻防场景自动生成正则规则，含名称/表达式/优先级/匹配示例。支持输入日志样本进行自适应生成。

### 6.2 ES 查询生成

**API 端点**: 
- `POST /api/v1/script-gen/es-query` — 单条 ES 查询
- `POST /api/v1/script-gen/es-query/batch` — 批量 ES 查询

生成完整的 ES Query DSL JSON，支持索引模式、时间范围、过滤条件等参数，可直接用于 Kibana 或 Elasticsearch 检索。

### 6.3 攻击溯源

**API 端点**: `POST /api/v1/script-gen/trace`

从多条日志中提取攻击链，识别攻击入口、扩散路径和最终目标，生成溯源脚本。

### 6.4 脚本优化

**API 端点**: `POST /api/v1/script-gen/optimize`

对已有的正则/ES 查询/SPL 查询进行纠错和优化，提升匹配精度和查询性能。

### 6.5 Splunk / ES 集成

**API 端点**: 
- `POST /api/v1/script-gen/splunk/search` — 执行 Splunk 搜索
- `POST /api/v1/script-gen/splunk/open-url` — 生成 Splunk Web UI 跳转链接
- `POST /api/v1/script-gen/splunk/test` — 测试 Splunk 连接
- `POST /api/v1/script-gen/splunk/config` — 保存 Splunk 配置到 .env（全局持久化）
- `POST /api/v1/script-gen/es/search` — 执行 ES Query DSL 搜索
- `POST /api/v1/script-gen/es/test` — 测试 ES 连接（返回集群名 + 版本号）
- `POST /api/v1/script-gen/es/config` — 保存 ES 配置到 .env（全局持久化）

支持通过 API 直接查询 Splunk / ES 数据，返回搜索结果，并可生成一键跳转 Splunk Web 的查看链接。Web 端系统设置面板支持测试连接 / 临时保存（localStorage）/ 保存到 .env 三种配置方式。详见 `docs/splunk-es配置说明.md`。

## 七、模块五：合规审计 ✅

**功能**: 标准问答 → 基线生成 → 合规自查

**API 路由**: `/api/v1/compliance/`

### 7.1 合规标准问答

**API 端点**: `POST /api/v1/compliance/qa`

基于 RAG 知识库检索，支持等保 2.0/网络安全法/数据安全法等标准问答。可指定资产类型和标准过滤条件，返回标准引用 + 详细说明 + 检查方法 + 违规风险。

### 7.2 基线生成

**API 端点**: `POST /api/v1/compliance/baseline`

根据资产数量、业务类型、设备类型、监控场景、行业属性等，自动生成个性化安全配置基线。

### 7.3 合规自查

**API 端点**: 
- `POST /api/v1/compliance/check` — 单环境合规检查
- `POST /api/v1/compliance/check/batch` — 批量合规检查

对当前环境进行合规差距分析，检查维度包括：日志留存天数、备份策略、防篡改、审计机制、NTP 同步、告警系统、堡垒机等，输出评分 + 整改步骤 + 优先级排序。

## 八、模块六：安全威胁狩猎 / 日志联合审查 🔗

**功能**: 多源日志关联分析 → 攻击链检测 → 场景联动

**API 路由**: `/api/v1/log-correlate/`  
**新增于 v3.0**

### 8.1 关联分析

**API 端点**: `POST /api/v1/log-correlate/correlate`

多源日志关联分析 — 检测攻击链。双引擎架构：关键词引擎（内置 16 种攻击链模式）+ LLM 引擎（降级语义分析）。支持 SSH/Web/防火墙等多类型混输，可配置时间窗口和分析深度。

### 8.2 文件关联分析

**API 端点**: 
- `POST /api/v1/log-correlate/upload` — 上传日志文件
- `POST /api/v1/log-correlate/file-crunch` — 文件关联分析
- `POST /api/v1/log-correlate/cleanup` — 清理临时文件
- `POST /api/v1/log-correlate/file-crunch-cleanup` — 分析+自动清理

支持单文件或多文件上传，进行大日志文件关联分析，分析完成后可自动清理临时文件。

### 8.3 跨模块联动

**API 端点**: 
- `POST /api/v1/log-correlate/to-trace` — 攻击链结果 → 生成攻击溯源脚本（联动 script-gen）
- `POST /api/v1/log-correlate/to-scenario` — 攻击链结果 → 下发实训场景（联动 training）

分析结果可一键转化为攻击溯源脚本或实训场景，实现从检测到处置到实训的完整闭环。

### 8.4 攻击链模式

**API 端点**: `GET /api/v1/log-correlate/patterns`

获取所有可检测的攻击链模式列表，覆盖 SSH 爆破提权、SQL 注入、横向移动、数据窃取、C2 通信、勒索软件、Webshell 等场景。

## 九、模块七：攻防实训 🎓

**功能**: 实训场景 → 答案校验（评分+讲解）→ 实训报告

**API 路由**: `/api/v1/training/`

### 9.1 实训场景

**API 端点**: `POST /api/v1/training/dispatch`

下发实训任务 — 获取场景列表和任务详情。提供多个攻防场景（SSH 暴力破解溯源、Web 攻击溯源等），支持按分类筛选。运维模式下该模块隐藏，需切换至实训模式。

### 9.2 提交答案与评分

**API 端点**: 
- `POST /api/v1/training/submit` — 提交答案校验
- `POST /api/v1/training/analyze-stream` — 流式分析（SSE 逐 token 返回）

双维度智能校验：规则校验 + LLM 语义校验。支持评分、答题讲解，SSE 流式输出答案解析。无需 LLM 时可纯规则评分降级。

### 9.3 实训报告

**API 端点**: `POST /api/v1/training/report`

生成完整实训报告，含任务完成率、得分统计、薄弱项分析、个性化提升方案。

## 十一、RAG 知识库架构

基于 **ChromaDB** 的 5 个 RAG 知识库：

| 知识库 | 数据来源 | 用途 |
|--------|---------|------|
| 日志基础库 | data/rule_data/ 日志特征/风险规则 | 日志识别、解析、风险研判 |
| 合规审计库 | data/rule_data/ 合规标准/基线 | 合规问答、基线生成 |
| 采集架构库 | data/rule_data/ 设备协议/采集模板/架构模板 | 设备匹配、采集方案、架构推荐 |
| 技术脚本库 | data/rule_data/ 脚本生成配置 | 正则/ES 查询/Splunk 生成 |
| 实训案例库 | data/rule_data/ 实训场景/标准答案 | 攻防实训、答题校验 |

知识库在服务启动时通过 `core.ai_base.kb_ingest.ingest_all()` 自动导入，LLM 降级时知识库仍可独立工作。

## 十三、CLI 命令行工具

项目内置 `log_trace_guard_cli/` 命令行版本（同级目录，仓库根），提供与 Web 版一致的 5 大业务模块 + AI 智能对话离线运行：

- **日志解析** — 识别/解析/研判/批量
- **日志采集** — 匹配/方案/故障
- **脚本生成** — 正则/ES 查询/Splunk SPL/攻击溯源/脚本优化/连接配置
- **合规审计** — QA/基线/检查
- **日志联合审查** — 关联分析
- **AI 智能对话** — 自由提问 + 意图识别调度

支持命令行模式（`--parse` / `--regex` / `--splunk-search` / `--es-search` 等，退出码 0/1/2），可从 GitHub Releases 独立下载，无需配置 Web 环境即可使用。
